# Security Policy

## Supported Versions

Puklic is in early development. Only the latest released version receives security updates.

| Version | Supported |
|---------|-----------|
| latest  | ✅        |
| older   | ❌        |

## Reporting a Vulnerability

If you discover a security issue, **please do not open a public GitHub issue.**

Instead, report it privately:

- **Preferred:** [GitHub Security Advisory](https://github.com/JanDamek/puklic/security/advisories/new)
- **Email:** damek@mazlusek.com

Please include:

- A description of the issue
- Steps to reproduce
- The version of Puklic affected
- Your assessment of the impact

You will receive an acknowledgement within 5 working days. If the issue is confirmed, we will work on a fix and coordinate a disclosure timeline with you.

## Scope

In scope:

- Bugs in Puklic source code that compromise user data, account access, or local system integrity
- Vulnerabilities in our build / release pipeline
- Issues in shipped dependencies that affect Puklic users

Out of scope:

- Issues in Discord's own services
- Social engineering attacks
- Issues requiring physical access to a user's unlocked device
- Theoretical issues without practical impact

## Responsible Disclosure

We follow a 90-day coordinated disclosure policy by default. We may release earlier with the reporter's agreement once a fix is available.
