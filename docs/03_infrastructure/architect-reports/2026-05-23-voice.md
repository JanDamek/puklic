# Voice Phase 3 — Architecture Plan (2026-05-23)

## 1. Goal & non-goals

**Goal.** Usable two-way voice on JVM desktop (Linux Wayland/X11, macOS). Join/leave a guild voice channel, hear others, be heard, mute/deafen, see speaking indicators.

**Non-goals (Phase 3.0):**
- DAVE / E2EE voice (MLS-based, deferred to 3.1)
- Android/iOS audio backends
- Noise suppression, echo cancellation
- VAD beyond trivial RMS gate
- Video / screenshare (Phase 4)
- Bitrate adaptation, FEC, DTX tuning

## 3. Tech choices

| Concern | Choice | Why |
|---|---|---|
| Opus | **concentus** `com.github.jitsi:concentus:1.0.2` | Pure JVM, no native build. ~1.5× slower than libopus but <1 ms encode per frame on M1 — irrelevant. Keeps binary <80 MB. Swap to JNI libopus later behind expect/actual if needed. |
| AEAD | **BouncyCastle 1.78** `XChaCha20Poly1305` | Discord requires `aead_xchacha20_poly1305_rtpsize` since Nov 2024. BC pure JVM, mature, no protobuf. |
| Voice WS | **Ktor Client WebSocket** | Already on classpath, same engine as main gateway. |
| UDP | **`java.net.DatagramSocket`** | Stdlib, blocking single thread per direction. No Netty. |
| Audio I/O | **`javax.sound.sampled`** | Stdlib, cross-platform (PipeWire-pulse shim on Linux). Adequate 20–40 ms latency. Abstracted behind expect for future native swap. |
| Devices | **`AudioSystem.getMixerInfo()`** | Stdlib, platform-stable mixer names. |

## 5. Voice gateway WS protocol

Endpoint: `wss://${endpoint}/?v=8`. Opcodes used:

| Op | Name | Dir | Use |
|---|---|---|---|
| 0 | Identify | C→S | `{ server_id, user_id, session_id, token }` |
| 1 | SelectProtocol | C→S | After IP discovery: `{ protocol: "udp", data: { address, port, mode: "aead_xchacha20_poly1305_rtpsize" } }` |
| 2 | Ready | S→C | `{ ssrc, ip, port, modes }` |
| 3 | Heartbeat | C→S | per Hello.heartbeat_interval |
| 4 | SessionDescription | S→C | `{ mode, secret_key: [u8;32] }` |
| 5 | Speaking | C↔S | `{ speaking: bitmask, delay: 0, ssrc }` |
| 6 | HeartbeatAck | S→C | echoes nonce |
| 7 | Resume | C→S | post-drop |
| 8 | Hello | S→C | `{ heartbeat_interval }` |
| 9 | Resumed | S→C | resume ok |
| 13 | ClientDisconnect | S→C | `{ user_id }` |

DAVE ops 14–18 ignored 3.0.

State machine: `Idle → AwaitingVoiceServer → ConnectingWs → AwaitingHello → Identifying → AwaitingReady → IpDiscovery → SelectingProtocol → AwaitingSessionDescription → Active → (Disconnecting|Failed)`. 10 s per-transition timeout; exponential backoff 1/2/4/8 s up to 5 attempts.

Trigger flow:
1. `VoiceClient.connect(guild, channel)` sends Op 4 VOICE_STATE_UPDATE on **main** gateway.
2. Main gateway dispatches VOICE_STATE_UPDATE (`session_id`) + VOICE_SERVER_UPDATE (`token`, `endpoint`).
3. Open voice WS.

## 6. UDP RTP transport

### IP discovery (74-byte packet)

```
offset  size  field
0       2     0x0001    Type: request
2       2     70        Length
4       4     ssrc
8       64    address (zero-padded)
72      2     port
```
Server replies with type `0x0002` and discovered external address+port.

### RTP packet

```
byte  0:   0x80              version=2, padding=0, ext=0, csrc=0
byte  1:   0x78              payload type Opus
bytes 2-3: sequence (u16 BE)
bytes 4-7: timestamp (u32 BE)
bytes 8-11: ssrc (u32 BE)
ciphertext (Opus + 16B tag)
nonce-counter (u32 BE, last 4 bytes)
```

Seq +1, timestamp +960 per 20 ms frame. SSRC from Ready. For `_rtpsize` variants AAD = 12-byte RTP header; nonce counter appended **after** ciphertext.

## 7. Encryption

`aead_xchacha20_poly1305_rtpsize`:
- Key: 32 B from Op 4 SessionDescription.
- Nonce: 24 B = `nonceCounter(u32 BE) || zero[20]`. Counter increments per outgoing packet; for incoming, read last 4 B of payload.
- AAD: 12 B RTP header.
- Wire: `RTP-header(12) || ciphertext+tag || nonce-counter(4)`.

```kotlin
val cipher = XChaCha20Poly1305()
cipher.init(forEncryption, KeyParameter(key), nonce24, aad12)
val out = ByteArray(cipher.getOutputSize(plaintext.size))
val n = cipher.processBytes(plaintext, 0, plaintext.size, out, 0)
cipher.doFinal(out, n)
```

Reuse cipher per direction; re-init each packet. `NonceGenerator` = AtomicInteger; wrap at 2^32 forces disconnect (2.7 years at 50 pps).

## 8. Capture pipeline

```
TargetDataLine (48k mono S16LE)
  → blocking read 1920 B = 960 samples = 20 ms (natural pacing)
ShortArray(960)
  → optional VAD (RMS < threshold × 5 frames → stop)
OpusEncoder.encode → ByteArray (~80–200 B at 64 kbps)
Encryptor.encrypt(opus, rtpHeader)
DatagramSocket.send
```

Single coroutine on `Dispatchers.IO`. Bitrate 64 kbps, complexity 10, voice signal. Stop-speaking = 5 silence frames `[0xF8, 0xFF, 0xFE]`. Local mute = skip loop + emit Speaking=0.

## 9. Playback pipeline

```
DatagramSocket.receive (blocking IO)
  → parse RTP → (ssrc, seq, ts)
  → split ciphertext + nonce
Decryptor.decrypt → opusBytes
PerSsrcStream[ssrc].jitterBuffer.push(seq, opusBytes)
  → consumer coroutine, 40 ms target buffer
OpusDecoder[ssrc].decode(opusBytes, fec=missingPrev) → ShortArray(960)
mixer accumulates (saturated)
SourceDataLine.write
```

One decoder per SSRC; lazy create, destroy after 10 s silence. JitterBuffer = ring of 8 by seq; hole → FEC. Single SourceDataLine; mixer 50 Hz. Speaking-indicator: per-SSRC last-packet-ts < 200 ms.

## 10. Device enumeration

```kotlin
AudioSystem.getMixerInfo().mapNotNull { info ->
    val mixer = AudioSystem.getMixer(info)
    val cls = if (direction == Capture) TargetDataLine::class.java else SourceDataLine::class.java
    val ok = mixer.targetLineInfo.any { cls.isAssignableFrom(it.lineClass) }
          || mixer.sourceLineInfo.any { cls.isAssignableFrom(it.lineClass) }
    if (!ok) null else AudioDevice(info.name, "${info.name} — ${info.description}", direction, isDefault = false)
}
```

Refresh on connect + 5 s tick when settings UI open.

## 11. Mute / deafen

- **Self mute**: stop capture loop; Op 5 Speaking=0; VOICE_STATE_UPDATE `self_mute=true` on main gateway.
- **Self deaf**: drop incoming after decrypt; VOICE_STATE_UPDATE `self_deaf=true`. Deaf implies mute (Discord UI convention).
- **Server mute/deaf**: read-only on `VoiceState.Connected` from VOICE_STATE_UPDATE dispatches.

Speaking bitmask: `MICROPHONE=1`, `SOUNDSHARE=2`, `PRIORITY=4`. Send `1` while talking, `0` when stopped.

## 14. Risks

1. **`javax.sound` on Wayland-only without PulseAudio shim** — surface error "install pipewire-pulse" at startup if `getMixerInfo()` empty.
2. **AEAD mode availability** — some voice regions may still negotiate legacy `xsalsa20_poly1305_lite`. Ship `xchacha20` only first, fail loudly, add fallback if needed.
3. **Concentus under load** — 20+ concurrent speakers may saturate a core. Mitigation: decoder pool, drop oldest SSRC if > 12 active.
4. **Voice WS v8 buffered resume** — poorly documented; reconnect may need fresh Identify. Validate empirically.
5. **Device hot-plug** — `javax.sound` doesn't signal; 5 s poll. On unplug `TargetDataLine.read` throws → catch, `Failed(recoverable=true)`, prompt device pick.
