# UI localization (i18n)

All user-visible texts of `:shared:compose-ui` live in Compose Multiplatform resources. English is the default; Czech is the first additional locale (PUKLIC-135).

## Location

- `shared/compose-ui/src/commonMain/composeResources/values/strings.xml` — English (default, always complete).
- `shared/compose-ui/src/commonMain/composeResources/values-cs/strings.xml` — Czech.
- Generated accessors: package `dev.puklic.ui.resources` (`Res.string.*`, `Res.array.*`), configured in `shared/compose-ui/build.gradle.kts` (`compose.resources`, internal to the module).

## Rules

- Composables read texts with `stringResource(Res.string.key, args...)`; day/month names come from the `calendar_*` string arrays via `stringArrayResource`.
- Keys are `snake_case`, prefixed by the screen or component (`login_`, `settings_`, `composer_`, `voice_` ...). Format arguments are positional (`%1$s`, `%2$d`).
- Both files must contain exactly the same keys. A key is added to both in the same commit.
- XML escaping: `\'` for apostrophes, `&amp;`, `&lt;`, `%%` for a literal percent sign.
- UI code must not build sentences from fragments; use one resource with arguments so translations can reorder words.

## Locale selection

The locale follows the system language of the device (Android, iOS, desktop JVM default locale). A language without a `values-<lang>` directory falls back to English. There is no in-app language switch.

## Adding a locale

1. Create `values-<lang>/strings.xml` with every key of the default file.
2. Verify the key sets match and the module compiles.

## Out of scope

- Discord content (messages, channel and user names), protocol identifiers, logs, exceptions.
- The brand name "Puklic".
- Native texts outside `:shared:compose-ui`: Android manifest and Info.plist strings (permission usage descriptions), desktop tray menu and the desktop update banner in `:desktop:app`.
